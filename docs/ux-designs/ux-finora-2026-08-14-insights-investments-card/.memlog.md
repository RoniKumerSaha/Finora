# Finora — Insights Investments card (Active / To mature) (2026-08-14)

## Run summary

User feedback: the hero stat at the top-right of the **Investments
card on `/insights`** currently shows the sum of all **maturity
values**. The user wants:

- "Total active" (sum of active principals) as the prominent stat.
- The maturity-value total shown in a different, smaller way — not
  as the dominant figure.

Originally interpreted as a change to `InvestmentsListScreen`, but
the user clarified: "no i wanted change in investement section in
insight" — the *Insights* Investments card (`InvestmentsCard` in
`InsightsScreen.tsx`). The Investments list page header is **not**
modified.

User selected visual: two-tile split in the card header —
`Active ৳ X | To mature ৳ Y` — both visible, both on the right side
of the title, both as peer values.

Mode: **fast path** — single-card visual change, no new tokens.

## Decisions

### D1 — Two-tile split in the Investments card header

The Investments card on Insights grows two stat tiles in the right
side of its existing header row:

```
┌────────────────────────────────────────────────┐
│ Investments         Active    To mature        │
│                     ৳ X       ৳ Y              │
└────────────────────────────────────────────────┘
```

- Title on the left (`h3-modal`, Fraunces): "Investments".
- Two stat tiles on the right (`Active` · `To mature`),
  comma-less two-column grid (`grid-cols-2`).

Both tiles are equal-weight, both visible at the same scale. The
user picked "Inline on the right (split per row)" from a
side-by-side preview, which gave them a peer pair rather than
a hero + subordinate caption.

### D2 — Math

- **Active** = sum of active investment **principals** across the
  investments returned by `investmentsForInsights(state)`. For DPS
  we use `dpsContributedSoFar(inv, transactions)` (the user's
  actual cash paid in); for FDR/savings we use `Number(inv.principal)`.
  This matches the convention established on the
  `InvestmentsListScreen` Summary card's "Total invested" tile.
- **To mature** = sum of `inv.maturityValue` across the same rows
  (the existing value previously shown alone). For DPS this is the
  type-aware annuity-due maturity value net of payouts; for FDR/
  savings it is the simple-interest maturity value net of payouts.

Both tiles are derived from the same `investmentsForInsights(state)`
selector the card already uses. The shader math exists; we just
add a second reduction.

### D3 — Empty state

When there are zero active investments:

- **Active** tile shows `৳ 0`.
- **To mature** tile shows `—` (matching the existing card's
  per-card empty-money treatment).

The empty-state message ("No active investments.") below
unchanged. The "+ Add an investment" CTA unchanged.

### D4 — Visual treatment (no new tokens)

| Element | Style | Notes |
|---|---|---|
| Tile label (eyebrow) | `text-[11px] text-muted uppercase tracking-wider font-semibold` | matches the Insights stat row eyebrows |
| Active value | `text-[20px] font-bold tabular accent` | accent ink to match the original money color |
| To mature value | `text-[20px] font-bold tabular primary` | primary ink — *gains* this color from the existing primary-tone treatment of the cash-flow "total expense" caption |

Two distinct hues differentiate the two tiles semantically:
**accent** for principal-at-work, **primary** for future money.
Both are existing tokens.

### D5 — What did NOT change

- `InvestmentsListScreen` (the `/investments` list page): no
  header change. The user's correction is explicit. The
  in-progress `Total active` change from the previous turn was
  reverted.
- The per-row maturity display in `InvestmentRow`: unchanged.
  Each row still shows its own maturity value on the right and its
  principal in the sub-line below. The headers add **aggregate**
  views; rows keep their **itemized** view.
- The Insights date-range pill behavior: unchanged.
