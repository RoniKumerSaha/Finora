# Finora — Settings/About panel (2026-08-14)

## Run summary

User feedback (with screenshot): the right side of `/settings` looks
empty. The Settings screen is currently a single column at
`max-w-[640px]`, leaving the rest of the content area as dead space.
Add an **About** panel on the right side so the screen reads as a
deliberate two-column layout instead of a thin column in a wide shell.

Source: `screenshots/SettingsScreen-empty-right.png` (user-supplied).

Mode: **fast path** — small additive change, no new tokens, one card,
one layout tweak. Capture intent with 2–3 quick questions, then ship.

## Decisions

### D1 — Two-column Settings, About on the right

Settings becomes a two-column layout on desktop:

- **Left column** keeps the existing `Theme / Backup / Demo data /
  Danger zone` stack. Slightly relaxed `max-w` (or removed) so the
  column breathes.
- **Right column** hosts a single new `About` card, sticky-ish at the
  top (no scroll coupling — it sits where it sits).

Mobile / narrow viewports fall back to a single column with About
*after* the existing sections (per spine — additive only, no removal).

### D2 — What lives in About

The About card carries only what is *about the product itself*. No
user data, no per-state values.

- **Product name** (Fraunces, h3-modal weight). Subtle rebrand cue.
- **One-sentence blurb.** "A Bangladesh-first personal finance
  notebook. Local-only, single user, one currency (BDT ৳)."
- **Version chip.** `v1.0.0` from `package.json` (read via
  `import.meta.env.VITE_APP_VERSION` with hard-coded fallback) — the
  user can see what build they're on when reporting issues.
- **Build / commit line** (optional, env-driven). A short SHA-style
  chip below the version when `VITE_COMMIT_SHA` is set; hidden
  otherwise. Marks pre-release builds.
- **Privacy line.** "All data lives in your browser. No accounts, no
  cloud, no telemetry." — single sentence, two clauses.
- **Links.** Three text links stacked, each with a `→` glyph:
  - "Help & shortcuts →" — links to nothing (deliberately hidden in
    V1 — see D3).
  - "What's new →" — links to `/insights` (placeholder, see D3).
  - "Reset →" — duplicates the danger callout's "Wipe all data"
    affordance as a low-weight text link (so a non-destructive-link
    path exists for power users).
- **Storage row** (informational only). "Storage: localStorage · ~X
  entries" where X = total count of accounts + transactions + goals
  + debts + investments. Surfaces storage state without diagnostic
  language.

### D3 — Links, scoped

The About card's links are the trickiest piece. Three of them:

- **"Help & shortcuts →"** — there is no `/help` page in V1. The link
  is omitted (not rendered) rather than render a 404 affordance.
  [NOTE for UX] Add a `/help` route in a follow-up run.
- **"What's new →"** — there is no `/changelog` route in V1. The link
  is omitted. The release-of-the-day is communicated through the
  commit history / PRD — not yet a product surface.
  [NOTE for UX] Promote this when a changelog surface exists.
- **"Reset →"** — duplicates the existing Danger-zone "Wipe all
  data" button. Rendered as a small text link. Same confirm
  dialog, same `useConfirm()` flow. This is the *non-button* way to
  reach reset, useful when the user wants to scan the Settings page
  without committing to a button click.

### D4 — No new tokens

About card uses the existing `.card` primitive. The version chip
uses the existing `.chip` primitive (selected variant). No new colors,
no new radii, no new typography roles.

### D5 — Layout rule

- Desktop (>= 768px): `grid-cols-[1fr_320px]` on a `max-w-[1100px]`
  container. Left column takes the available width; right column
  pins at 320px.
- Mobile / narrow (< 768px): single column, About card renders
  *after* Danger zone, separated by the standard section gap.

### D6 — Voice

- The About card matches the parent run's voice: warm, factual,
  un-marketing. "Local-only. No accounts. No telemetry." — short
  clauses, no adjectives.
- The version chip carries no emoji. No "🎉 v1.0.0". Just `v1.0.0`.
