02 Tag palette

Payout Debt received Debt payment Goal Category fallback

Each tag's tone is semantic: payout = accent (matches the gold "to mature" treatment in investments), debt payment = primary (you're paying down debt — a savings-positive action), debt received = info (someone is paying you back), goal = success (you're saving toward something).

03 Tone rationale

Payout
Payout → maturity-linked investment income; matches the gold investment card.
Debt payment
Debt payment → you're paying down debt; primary green (savings-positive).
Debt received
Debt received → someone is paying you back; info blue (distinct from payout).
Goal
Goal → contribution toward a savings goal; success green.

05 How the pill is built

Compact pill that sits inline with the title (next to the row's name, not below the subtitle). Color comes from the existing palette — no new tokens. Tone picks automatically based on tx.linkedInvestmentId, tx.linkedDebtId, or tx.linkedGoalId, with direction logic for debt (i_owe = primary green, owed_to_me = info blue).

.tag { display: inline-flex; align-items: center; gap: 4px; padding: 2px 8px; border-radius: 999px; font-size: 10.5px; font-weight: 700; text-transform: uppercase; letter-spacing: 0.06em; } .tag.payout { background: var(--accent-soft); color: var(--accent); } .tag.debt { background: var(--info-soft); color: var(--info); } .tag.debt-out { background: var(--primary-soft); color: var(--primary); } .tag.goal { background: var(--success-soft); color: var(--success); } .tag.muted { background: rgba(148,165,156,.12); color: var(--muted); }

06 Spec decisions

  • Position: inline with title, right of the row name. Stays visible on hover/collapse, doesn't fight the subtitle.
  • Subtitle cleanup: removes the redundant trailing · payout / · debt text — the tag replaces it. Account name stays in the subtitle.
  • Precedence: investment > debt > goal if somehow linked to multiple (rare; current data model doesn't allow it, but cheap to be defensive).
  • A11y: pill text is semantic ("Payout", "Debt payment") so it reads correctly to screen readers; tone is supplementary, not the only signal.
  • Where to apply: transactions list (grouped + flat) and home "Recent activity" — both use the same <TxRow> so they stay in sync automatically.
