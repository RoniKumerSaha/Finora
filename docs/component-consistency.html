8. Placeholder text

Today: no canonical placeholder token — inputs inherit text-ink and rely on browser opacity. Some inline editors add placeholder:text-muted or placeholder:italic placeholder:opacity-70 inconsistently.

Rule

  • Add --muted-2 token (already proposed in text-color rules).
  • Define .input::placeholder { color: var(--muted-2); } in app.css so every input gets the placeholder color automatically.
  • Inline editors (e.g. EventPlanDetailScreen) get italic + opacity-70 if they're truly "ghost" fields; otherwise just the standard placeholder.
standard (no focus)
italic ghost (inline editor)

10. Migration checklist

  1. Add missing tokens to theme.css: --muted-2, --*-on variants, --placeholder.
  2. Build one shared <Stat> in src/components/Stat.tsx; replace 5 duplicates.
  3. Standardize Chip vs Pill as two exports from src/components/Chip.tsx; replace 4 ad-hoc atoms.
  4. Migrate modals (ConfirmDialog, GoalDetail, InvestmentDetail, EventPlanDetail) to use .card + shadow-modal.
  5. Replace raw cancel button in ConfirmDialog.tsx with <Button variant="secondary">.
  6. Migrate hand-rolled inputs in BatchBudgetEditor, CardTotalChecker, EventPlanDetail to <Field> + <Input>.
  7. Unify progress bar: make SplitBar use the same 4px track + 200ms transition as InvestmentProgressBar.
  8. Add ::placeholder rule in app.css; remove inline placeholder:text-muted calls.
  9. Lint rule: block inline style="color:...", bg-surface border border-border rounded-card triples, raw <button> in non-icon contexts.
