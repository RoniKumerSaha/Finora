Transactions — nine more ways

The first nine alternatives all made the same bet: the transaction is a row, and the page is a container for rows. They differed in emphasis, but the shape was the same every time.

These nine break that bet. Each one argues the page is something else entirely — a running balance, a calendar, a category river, a set of daily postings, a net-worth bridge, a search console, a spending map, an account book, a ribbon. Same data, same palette, different subject.
