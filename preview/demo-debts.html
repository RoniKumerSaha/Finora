Debts — the IOU slips

A debt is a promise, not a holding — so the card is a perforated document rather than a tile. The stamp states the polarity ("I owe" / "Owed to me") so the direction is readable before any number is; a flat debt gets a tear-off stub down the left margin; a loan gets an APR rate seal, because a loan is an instrument with a rate.

How it works: Each debt records an opening transaction for the cash that gave rise to it — borrowed cash lands as Income in your account for i_owe; lent cash lands as Expense for owed_to_me. Use the Pay now / Receive now chip on a card to record a partial repayment against the same account. For loans with interest, each payment is split into interest (calculated on the outstanding principal) and principal — only the principal portion reduces what you still owe.

The tear-off stub is what makes a flat debt read as an IOU slip — it's the counterparty's copy, perforated down the left margin. A loan has no stub, because a loan is a contract with a rate, not a note between two people.
