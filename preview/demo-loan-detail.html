Loan detail — the projection, on the same certificate

A loan plan is a projection, so it wears the debt certificate's instrument shell — the same red paper, the same engraved fields, the same rail. The only difference is the PLANNED stamp: dashed, grey-worded, red-bordered, because no money has moved. The amortisation table below it is a ledger sheet — a ruled page of the same paper.

How it works: the EMI is fixed for the whole term. Early in the schedule most of each payment is interest; by the last installment it is almost all principal. The table on the left shows that split row by row.
The stamp is the point. A projection is a promise, not a receipt — so the word Planned is stamped across it in grey, with a dashed border so it reads as an annotation rather than an official mark.
Projections never touch your ledger. Nothing here becomes a transaction, and no account balance moves until you take a real loan and record it yourself.
