Flow bar — the segmented meter

Not a solid bar. A row of discrete blocks, like an equalizer or a barcode — the length is counted in blocks, not pixels, so every row in the column shares exactly the same scale and the twelve months line up block-for-block.

M1 grows from the left edge (a plain meter). M2 grows from a zero axis outward, so saved and overspent read as opposite directions. M3 is M2 with visible empty slots, so "nothing moved" is visible rather than absent. M4 uses hollow ticks. M5 adds a baseline track under the blocks. No scale — the blocks themselves are the measure.

1A solid bar has no countable units. The eye can judge "longer" but not "how many times longer" — a ৳6,11,000 bar and a ৳3,05,500 bar are only comparable by eye.
2Segments make the comparison countable. Twenty-eight blocks against fourteen — the ratio is something you can count, not estimate.
3Segments read as a meter, not a chart. That is a different, more physical signal: this row is filling up, this one is draining.
